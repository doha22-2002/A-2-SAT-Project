# A-2-SAT-Project

This project implements a linear-time 2-SAT solver using Kosaraju's
Strongly Connected Components (SCC) algorithm.

## Features
- Linear-time 2-SAT core (O(n + m))
- Graph-to-2CNF reduction
- Degeneracy-aware clause generation
- Fallback mechanism for dense graphs
- Optional PNG visualization
